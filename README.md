# .Aai — AI Based Tutor ("The teacher, understand you")

## Introduction

**.Aai** is a modern, responsive educational web application and Retrieval-Augmented Generation (RAG) tutoring workspace designed to help students learn directly from their own course materials. Students upload study documents (PDF, DOC, DOCX, PPT, and PPTX up to 10 MB), select which files to study from, and ask factual or numerical questions in a guided chat interface.

Every answer generated by **.Aai** is strictly grounded in retrieved passages from the uploaded documents—complete with verified page, slide, and section citations, expandable supporting excerpts, programmatically verified step-by-step calculations for numerical problems, and on-demand practice quizzes. When an answer is not supported by the uploaded materials, **.Aai** explicitly refuses to guess and explains what information is missing.

---

## Features

- **Clean, Responsive Learning Dashboard**
  - Sidebar navigation and adaptive main workspace for desktop, tablet, and mobile screens.
  - Light and Dark mode with consistent typography, spacing, and smooth loading animations.
  - **Dashboard Home** displaying total uploaded documents, total questions asked, recent documents, recent conversations, and quick document upload actions.

- **Multi-Format Document Management**
  - Drag-and-drop or file picker upload strictly limited to **PDF, DOC, DOCX, PPT, and PPTX** formats (maximum **10 MB** per file).
  - Deep server-side validation across file extension, MIME type, binary magic bytes, and OpenXML archive structure—automatically rejecting empty, oversized, unsupported, or corrupted files.
  - **SHA-256 Duplicate Detection**: Warns on duplicate uploads (HTTP `409`) and offers **Re-index** or **Skip** options.
  - Displays document name, format, upload date, chunk count, and real-time processing status (*Extracting → Chunking → Embedding → Ready*), with inline preview, re-indexing, and deletion.

- **Grounded RAG AI Tutor Chat**
  - Answer questions across one or multiple selected study documents simultaneously.
  - Structured **Answer Cards** containing:
    - Direct answer and clear teacher-style conceptual explanation.
    - Evidence strength indicator and confidence score.
    - Expandable **Source Citations** with exact document name, page/slide/section label, semantic relevance score, and verbatim supporting passage.
    - Step-by-step **Numerical Solutions** with formula selection, extracted input values, and programmatic arithmetic verification (safe recursive-descent parser, zero `eval`).
  - **Strict Unsupported Question Detection**: Refuses off-topic or unsubstantiated questions with zero fabricated citations and explains specifically what material is missing.
  - Conversation history persistence and new chat session management.

- **On-Demand Practice Quizzes**
  - Generate customizable multiple-choice and numerical practice quizzes (*Foundational*, *Standard*, or *Challenging* difficulty, optional topic focus) strictly grounded in selected documents, with verified source citations and step-by-step explanations for each question.

- **Workspace Isolation Without Sign-In**
  - Anonymous browser workspace isolation (`X-Workspace-Id` header) keeps uploaded files, extracted metadata, vector embeddings, and chat history separated per workspace on local disk and browser storage without requiring login.

## Input and Output

### 1. Document Upload & Indexing (`POST /api/documents/upload`)

- **Input**:
  - `file` (`multipart/form-data`): A single **PDF, DOC, DOCX, PPT, or PPTX** file up to **10 MB**.
  - `duplicateStrategy` (optional): `"prompt"` (default) or `"reindex"`.
  - Header: `X-Workspace-Id` (`8–64` alphanumeric, underscore, or hyphen characters).
- **Output**:
  - **Success (`201 Created`)**: Indexed document metadata (`id`, `name`, `format`, `sizeBytes`, `pageCount`, `chunkCount`, `status: "ready"`, extracted segments, and `lastIndexedAt`).
  - **Duplicate Detected (`409 Conflict`)**: `{ duplicate: true, existingDocument, error }` prompting the user to **Re-index** or **Skip**.
  - **Validation Rejection (`400` / `401` / `413` / `422`)**: Clear JSON `{ error }` describing unsupported format, oversized file, missing/invalid workspace token, empty file, or corrupted binary/archive structure.

### 2. Grounded RAG Question Answering (`POST /api/rag/ask`)

- **Input**:
  ```json
  {
    "question": "A 4 kg object moves at 6 m/s. Calculate its kinetic energy using the chapter formula.",
    "documentIds": ["doc_1234567890abcdef"],
    "history": []
  }
  ```
- **Output (Supported Answer — `200 OK`)**:
  - `isSupported`: `true`
  - `evidenceStatus`: `"strong"` or `"moderate"`
  - `confidenceScore`: Numeric confidence score (`0–99`)
  - `directAnswer`: Concise, direct answer grounded in retrieved chunks
  - `explanation`: Clear pedagogical explanation
  - `numericalSolution` *(when applicable)*: `{ formula, inputValues, steps, finalAnswer, verifiedProgrammatically, verificationNote, sourceReference }`
  - `citations`: Verified array of `{ chunkId, documentId, documentName, pageOrSection, sectionHeading, supportingPassage, relevanceScore, verified: true }`
  - `checkedDocuments`: List of document names searched
- **Output (Unsupported Question — `200 OK`)**:
  - `isSupported`: `false`
  - `evidenceStatus`: `"insufficient"`
  - `directAnswer`: `"Insufficient information in your uploaded documents to answer this question."`
  - `missingInformation`: Clear description of what facts, values, or concepts are missing from the selected documents
  - `citations`: `[]` (strictly zero fabricated citations)

### 3. On-Demand Practice Quiz (`POST /api/rag/quiz`)

- **Input**:
  ```json
  {
    "documentIds": ["doc_1234567890abcdef"],
    "questionCount": 5,
    "difficulty": "standard",
    "topicFocus": "Kinetic Energy"
  }
  ```
- **Output (`200 OK`)**:
  - `{ title, difficulty, sourceDocumentNames, questions[] }` where each question includes `question`, `type` (`"multiple-choice"` or `"numerical"`), 4 `options`, `correctOptionIndex`, `explanation`, optional `calculationSteps`, and a verified source `citation`.

## Tech Stack

| Layer | Technologies |
| :--- | :--- |
| **Frontend** | React 19, TypeScript, Vite 8, Tailwind CSS v4, Lucide React, Motion |
| **Backend** | Node.js, Express, TypeScript (`tsx`), Multer |
| **AI & RAG Pipeline** | `@google/genai` SDK — `gemini-embedding-2` (3072-dim dense chunk & query embeddings), `gemini-4-hydrogen` (`ThinkingLevel.LOW`) with resilient failover to `gemini-3.1-flash-lite` |
| **Document Processing** | `unpdf` (PDF text extraction + Gemini OCR fallback for scanned PDFs), `mammoth` (DOCX), `jszip` (PPTX XML/notes), `word-extractor` + RTF parser (DOC), binary `TextCharsAtom` parser (PPT) |
| **Vector & Metadata Storage** | Workspace-isolated disk-persisted vector store (hybrid cosine similarity + lexical overlap scoring), local JSON metadata & original file storage, browser IndexedDB (`idb`) / `localStorage` |
| **Verification & QA** | Safe recursive-descent arithmetic verifier (`server/rag/mathVerifier.ts`), chunk provenance citation validator (`server/rag/citationValidator.ts`), 28-case end-to-end automated QA suite (`tests/rag-qa.test.ts`) |

## Running the Project Locally

### Prerequisites

- **Node.js** v20 or later
- **npm** v10 or later
- A **Google Gemini API key**

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment Variables

Copy `.env.example` to `.env` and add your Gemini API key:

```bash
cp .env.example .env
```

Update `.env`:

```env
GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
APP_URL="http://localhost:3000"

# Optional RAG pipeline tuning
RAG_DATA_DIR=".aai-data"
RAG_MIN_SIMILARITY="0.42"
RAG_TOP_K="8"
```

### 3. Start the Development Server

```bash
npm run dev
```

This starts the Express RAG API and Vite frontend together on **`http://localhost:3000`**.

### 4. Type-Check & Run Production Build

```bash
npm run lint
npm run build
NODE_ENV=production npm start
```

### 5. Run the Automated End-to-End QA Test Suite

With the app running on `http://localhost:3000`, execute:

```bash
npm run test:qa
```

This runs all 28 automated checks covering multi-format uploads, invalid/corrupted/oversized/duplicate/unauthorized rejections, factual Q&A, numerical Q&A with math verification, unsupported refusal detection, multi-document retrieval, quiz generation, workspace isolation, disk persistence, re-indexing, and deletion cleanup.
